# 📘 Manual configuration / 手動設定ガイド

For people who want to **configure it themselves** instead of letting an AI agent do it. `setup.ps1`
creates the templates, so after that you only edit these two files: **`agent/.env`** and
**`agent/config.json`** (both gitignored).

> 🇯🇵 AI に任せず自分で設定したい人向け。基本は `setup.ps1` が雛形を作るので、あとは
> `agent/.env` と `agent/config.json` の2ファイルを編集するだけ（どちらも gitignore 済み）。

---

## 1. `agent/.env` — secrets & URLs

Copy `agent/.env.example` to `agent/.env` and fill in the values.

| Key | Required | Role |
|---|---|---|
| `AGENT_TOKEN` | ✅ | Agent auth token. Auto-generated by `setup.ps1`. Manually: `python -c "import secrets;print(secrets.token_urlsafe(32))"` |
| `CLOUDFLARE_TUNNEL_TOKEN` | ✅ | Cloudflare Tunnel token (legacy name `CF_TOKEN` also accepted) |
| `PUBLIC_URL` | ✅ | Public URL (e.g. `https://your.example.com`). `PASSKEY_RP_ID`/CORS are derived from it |
| `PORT` | – | Agent listen port (default 8766). The watchdog proxies to 8766, so leave it unless you also change `watchdog.py` |
| `PC_NAME` | – | A display name for this PC |
| `VSCODE_TUNNEL_NAME` / `CURSOR_TUNNEL_NAME` | – | IDE tunnel names (use unique values) |
| `PASSKEY_RP_NAME` | – | Display name shown at login |

> ⚠️ **Never put `ANTHROPIC_API_KEY` here** (it makes things run on metered API billing; the agent refuses to start if it detects it).

---

## 2. `agent/config.json` — projects & engines

Template: `agent/config.example.json`.

### Register projects (the guardrail: AI runs only under these paths)
```jsonc
"projects": [
  { "id": "myproj", "name": "my-app", "path": "C:\\path\\to\\my-app", "description": "" }
]
```
You can also add more via "+ Add project" in the phone UI.

### Engine config (optional; only when using something other than Claude Code)
```jsonc
"default_engine": "claude_code",          // default engine. If omitted, claude_code
"engines": {
  "gemini":      { "cmd": "gemini", "args": ["-p", "{prompt}"], "prompt_via": "arg",   "strip_env": ["GEMINI_API_KEY"] },
  "codex":       { "cmd": "codex",  "args": ["exec"],            "prompt_via": "stdin", "strip_env": ["OPENAI_API_KEY"] },
  "antigravity": { "cmd": "agy",    "args": ["-p", "{prompt}"], "prompt_via": "arg" }
}
```

| Field | Meaning |
|---|---|
| `cmd` | Command to run (resolved on PATH; Windows `.cmd`/`.bat` are fine) |
| `args` | Argument list. `{prompt}` / `{cwd}` are substituted |
| `prompt_via` | `stdin` (prompt to standard input) or `arg` (prompt into the `{prompt}` argument) |
| `strip_env` | Env vars to strip from the subprocess (avoids that engine's API-key billing) |

**Switching engines:**
- Change the global default → change `default_engine`
- Per request → set the `engine` field in the `/command` request (e.g. `"engine":"gemini"`)

> Claude Code uses a dedicated adapter (rich display, conversation resume). Everything else runs via
> `generic_cli` and returns **plain-text output**. If you need rich display or resume, copy
> `engines/claude_code.py` and add a dedicated adapter.
>
> ⚠️ Each CLI's launch args (`cmd`/`args`/`prompt_via`) **change with versions**. The above are templates,
> so run something like `cmd -p "test"` once against your local CLI to confirm.

> 🇯🇵 Claude Code は専用アダプタ（リッチ表示・会話継続）。それ以外は `generic_cli` が素テキストで返す。
> 各CLIの起動引数はバージョンで変わるので、手元のCLIで1度確認してから設定すること。

## 3. When you edit the UI (version triple-sync)

When you change anything under `ui/`, **bump three files to the same number** (so updates punch through stale caches):
- `APP_VERSION` in `ui/index.html`
- `APP_JS_VERSION` in `ui/app.js`
- `CACHE_KEY` in `ui/sw.js` (`ai-hub-static-vNN`)

Emergency escape: add `?nosw=1` to the URL (deletes all Service Workers + reloads).

## 4. Cloudflare Tunnel

1. Cloudflare Zero Trust → Networks → Tunnels → Create to get a **token** → `.env` `CLOUDFLARE_TUNNEL_TOKEN`
2. Set a Public hostname on your domain pointing at `http://127.0.0.1:8765`
3. Put that hostname in `.env` as `PUBLIC_URL`

Place `cloudflared.exe` in `tunnel-setup/` (`setup.ps1` downloads it from the official source if missing).

### Tunnels other than Cloudflare (ngrok / Tailscale Funnel / frp, etc.)
Anything that can expose `127.0.0.1:8765` over public HTTPS works. But mind the **security detection:**

The watchdog distinguishes "over the internet vs. local on the PC" by **the presence of a header**, and
grants privileges (like adding devices) only to local. The default is Cloudflare's `cf-connecting-ip`.
Other tunnels don't add that header, so **as-is, internet traffic gains local privileges** — a hole.
Fix it in `agent/.env`:

| `.env` | Purpose |
|---|---|
| `REMOTE_MARKER_HEADER=<header>` | Specify a header the tunnel **always adds** (e.g. for Tailscale Funnel, `Tailscale-User-Login`) |
| `ASSUME_REMOTE=1` | Fail-safe. Treat every proxy as remote — closes the hole, but you add devices from the PC at `http://127.0.0.1:8765/ui/` |

For tunnels you're not sure about, **`ASSUME_REMOTE=1` is the safe choice.**

> 🇯🇵 Cloudflare 以外のトンネルは `cf-connecting-ip` ヘッダが無く、そのままだとリモートがローカル特権を得る穴になります。
> `REMOTE_MARKER_HEADER` でそのトンネルが必ず付けるヘッダを指定するか、確信が持てなければ `ASSUME_REMOTE=1`（フェイルセーフ）を使ってください。

---

## 5. Start & apply changes

- Start: `start-all.ps1` (cloudflared / watchdog:8765 / agent:8766 / IDE tunnels)
- After editing `.env` or `agent/*.py`, **restart the agent** to apply (just re-run `start-all.ps1`)
- Add a device (QR) from the PC locally at `http://127.0.0.1:8765/ui/`

## 6. Troubleshooting

### Opening on the phone gives a **502** (works locally but won't connect)
The cause is almost always **an IPv4/IPv6 mismatch in resolving `localhost`.** If cloudflared, etc. hits
`localhost` over IPv6 `::1` while the watchdog only listens on IPv4 `127.0.0.1`, you get "connection
refused even though it's loopback," and the tunnel returns 502. If the tunnel log shows
`dial tcp [::1]:8765 ... refused`, that confirms it.

→ **The watchdog listens on both IPv4 (`127.0.0.1`) and IPv6 (`::1`) loopback**, so updating to the latest
version (`git pull` → re-run `start-all.ps1`) fixes it. If you're on an old version and can't update, the
workaround is to change the Cloudflare Public Hostname Service from `http://localhost:8765` to
`http://127.0.0.1:8765`.

When in doubt, the fastest path is to **have your AI agent read this repo and ask it** (see [AGENTS.md](../AGENTS.md)).

> 🇯🇵 スマホで 502 になるのはほぼ `localhost` の IPv4/IPv6 解決ずれ。最新版の watchdog は IPv4/IPv6 両ループバックで listen するので、
> `git pull` → `start-all.ps1` 再実行で直ります。困ったら AI エージェントにこのリポを読ませて聞くのが一番早いです。
